# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/nighthawk909/snipforge/security/advisories/new).
You'll get a response within 7 days. Fixes ship as a new release, and the advisory is published
once users have had time to update.

## Supported versions

Only the latest release gets security fixes. The app's tray menu has **Check for updates**.
